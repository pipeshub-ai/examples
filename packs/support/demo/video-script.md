# Sixty-second demo: script

A screen recording for the README, a post, or a talk. Record it on the Acme
Corp demo data, signed in as Bob, with the Support Investigation Copilot pack set up
in one client (Claude Code or Omnigent). Keep the answer on screen long enough
to read the citations.

| Time | On screen | Voice-over |
| --- | --- | --- |
| 0–8 s | A client with an empty prompt | "A customer says their export keeps timing out. Has this happened before?" |
| 8–15 s | Type: *Which customers reported export timeouts, and what fixed it?* | "Ask it the way you'd ask a colleague." |
| 15–35 s | The answer appears with sources: the ServiceNow cases, SUP-114, PR #211, the runbook | "Three customers, one escalation, one engineering fix, and the runbook for what to do now." |
| 35–45 s | Click one citation and show the record | "Every claim points back to the case or ticket it came from." |
| 45–55 s | Ask: *What happened with Contoso's invoice that showed VAT on an exempt line?* | "It follows a billing problem from support into finance, too." |
| 55–60 s | The PipesHub and examples repository links | "Connect your own help desk, tracker and chat, and it answers for your team." |

Before recording, run the questions once and check the citations on screen
match the ones named in the voice-over; answers can vary between runs.
