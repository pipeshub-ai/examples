# Sixty-second demo: script

A screen recording for the README, a post, or a talk. Record it on the Acme
Corp demo data, signed in as Alice, with the Marketing Launch Copilot set up
in one client (Claude Code or Omnigent). Keep the answer on screen long enough
to read the citations.

| Time | On screen | Voice-over |
| --- | --- | --- |
| 0–8 s | A client with an empty prompt | "You're writing the launch recap and need the facts straight." |
| 8–15 s | Type: *When did we launch background exports, and why did we pick that date?* | "Ask it the way you'd ask the launch manager." |
| 15–35 s | The answer appears with sources: the launch plan, the `#launch` thread, PR #211 | "21 April, because the launch waited a week after the engineering fix went live." |
| 35–45 s | Ask: *How did the background exports launch campaign perform?* | "The numbers come straight from the results document, with the period they cover." |
| 45–55 s | Signed in as Alice, ask what launches next | "Only the launch core team sees the embargoed brief; anyone else gets nothing." |
| 55–60 s | The PipesHub and examples repository links | "Connect your own tools, and it answers for your launches." |

Before recording, run the questions once and check the citations on screen
match the ones named in the voice-over; answers can vary between runs.
