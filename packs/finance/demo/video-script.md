# Sixty-second demo: script

A screen recording for the README, a post, or a talk. Record it on the Acme
Corp demo data, signed in as Alice, with the Finance Operations Copilot pack set up
in one client (Claude Code or Omnigent). Keep the answer on screen long enough
to read the citations.

| Time | On screen | Voice-over |
| --- | --- | --- |
| 0–8 s | A client with an empty prompt | "A customer's invoice was wrong last month. Is it fixed, for them and for everyone?" |
| 8–15 s | Type: *Why was Contoso's invoice wrong, and has the billing rule been fixed?* | "Ask it the way you'd ask a colleague in finance." |
| 15–35 s | The answer appears with sources: SUP-121, FIN-37, FIN-38 | "One ticket fixed their invoice; another fixed the rule behind it, and found three more." |
| 35–45 s | Ask: *How much can I spend on a purchase without my manager's approval?* | "Policy questions come straight from the policy, with the thresholds." |
| 45–55 s | Signed in as Alice, ask for the card processing rate | "Contract terms only come back for the people allowed to read the contract." |
| 55–60 s | The PipesHub and examples repository links | "Connect your own tools, and it answers for your finance team." |

Before recording, run the questions once and check the citations on screen
match the ones named in the voice-over; answers can vary between runs.
