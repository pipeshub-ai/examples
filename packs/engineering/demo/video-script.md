# Sixty-second demo: script

A screen recording for the README, a post, or a talk. Record it on the Acme
Corp demo data, signed in as Bob, with the Engineering Knowledge Copilot set
up in one client (Claude Code or Omnigent). Keep the answer on screen long
enough to read the citations.

| Time | On screen | Voice-over |
| --- | --- | --- |
| 0–8 s | A terminal or Omnigent, empty prompt | "New on the team, and you want to know why the billing worker retries the way it does." |
| 8–15 s | Type: *Why was the payment service architecture changed, and how was the decision made?* | "Ask it the way you'd ask a colleague." |
| 15–35 s | The agent searches, then the answer appears with sources: INC-2031, the `#eng-payments` thread, the design doc, PR #482 | "The answer comes from four places: the incident in Jira, the Slack thread where the fix was argued, the design doc, and the pull request." |
| 35–45 s | Click one citation and show the record | "Every claim points back to where it came from." |
| 45–55 s | Ask: *Who reviewed PR #482, and what did Dana ask for before it merged?* | "Follow-ups work the same way, down to the review comment." |
| 55–60 s | The PipesHub and examples repository links | "Connect your own GitHub, Jira, Slack and Drive, and it answers for your team." |

Before recording, run the two questions once and check the citations on
screen match the ones named in the voice-over; answers can vary between runs.
